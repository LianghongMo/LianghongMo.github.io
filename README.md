# lianghongmo.github.io

Personal website of Lianghong Mo, served by GitHub Pages.

- `index.html` — the whole site (single page). Edit text here.
- `css/style.css` — the only stylesheet; colours are CSS variables at the top, with a dark-mode block.
- `cv/Lianghong_Mo_CV.pdf` — the CV linked from the header and footer. Replace the file to update.
- `img/RB.jpg` — the header photo (circular crop, 128 px). Swap in a square headshot to change it.
- `scholarpdf/` — undergraduate talks and notes linked under "Talks and Notes".
- `en/` — redirects from the old page URLs.
- `googlea9c1648423e5daaf.html`, `baidu_verify_KgDsOL5wx3.html` — search-console verification, keep.

No build step: push to `master` and GitHub Pages serves it.
